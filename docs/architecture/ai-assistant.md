# Invekta AI — Gemini provider

The existing two-field composer, recipient resolution, brand knowledge, local templates and access rules are preserved. The only external provider is now Google Gemini; no draft persistence, additional form controls, new schema or migration is introduced. The active backend settings are `CRM_AI_ENABLED` (false by default), `CRM_GEMINI_API_KEY` and `CRM_GEMINI_MODEL` (default `gemini-3.1-flash-lite`). Legacy Groq/OpenAI keys are never reused or forwarded. Free Tier must be selected in Google AI Studio; the CRM does not change billing, auto-upgrade, retry or fall back to another model/provider.

`ai_provider.py` uses the existing urllib transport, fixed HTTPS Google host, a validated model path and `x-goog-api-key` header rather than a query parameter. The native `generateContent` payload separates `systemInstruction` from user/CRM `contents`, requests bounded JSON through `responseMimeType`/`responseJsonSchema` and validates against the existing GeneratedDraft schema. It accepts one STOP candidate and text parts only, excludes thought parts and rejects blocked, truncated, malformed, empty and oversized outputs. No SDK/dependency/lockfile changes. TLS/proxy handling and the 45-second timeout remain.

Generation still authorizes the active session, membership, company ownership and explicitly selected contact/opportunity before the request, and rechecks access after the provider returns. Only the selected company, contact names/positions, sender, explicit input and current brand knowledge are sent. Automatically resolved recipient emails remain in CRM; no other customers, attachments or organization knowledge are included. Arbitrary notes, incoming mail and brand facts are data rather than instructions that can override the system policy. Output is editable plain text and never sent automatically.

The existing user-row lock and 20-attempt/15-minute budget stay in place. Missing configuration consumes no attempt; provider failure consumes an attempt. AiAttempt stores actor/time without the prompt or output. Generated drafts/edits live only in React state; refresh clears them. Existing AiDraft data is untouched, legacy GET remains private and POST/PATCH remain retired. `GET /ai/status` reports `gemini` or `templates`, configuration state, model and the same knowledge-administration capability. Public route paths remain unchanged.

`gemini_errors.py` closes and bounds errors to 8 KiB, allows only known Google diagnostic codes and never returns upstream text, request URLs, headers or exceptions. It distinguishes invalid keys, permission denial, missing model, quota, unsupported account/region, invalid request and service failure. `python -m app.check_ai_connection` makes one generic generation through the same client, without DB access or printing generated text; disabled/missing-key mode stops before networking. No runtime keys or production connection tests were provisioned by this code change.

Mocked transport regressions cover the native API contract, JSON schema/output checks, blocked/truncated/non-text/thinking responses, byte bounds, safe HTTP/timeout diagnostics, model-path validation and old-key isolation. Existing API tests preserve ownership, brand knowledge scoping, CSRF, refreshed recipients, rate budgets, no persistence and revoked-session handling. Full tests run only against isolated local PostgreSQL `_test`. A live Gemini key/model and human review of Serbian text remain an explicit post-configuration check. Free Tier data handling follows Google's terms; do not assume zero retention.
